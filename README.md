# Vakeiro

Site de fã (paródia) do streamer Euler Vakeiro — [twitch.tv/vakeiroo](https://www.twitch.tv/vakeiroo).

Single-page cyberpunk HUD com dados reais via Decapi.me + conteúdo satírico hardcoded.

## Stack
Vite · React 18 · TypeScript · Tailwind v4 · framer-motion · SWR

## Dev
```bash
npm install
npm run dev
```

## Deploy
Push para `main` → Vercel auto-deploy.
